# AL_Ternate Buffer
Simple DI buffer for recording purposes. The basic idea is one input, two outputs, 

## Requirements
- Able to accept a single mono or stereo signal at a high-impedance input (mono jack input will output on both channels)
- Have two identical outputs buffering the same mono or stereo signal to each output
- As the name implies, this device will have unity gain; this is a buffer, not an amplifier
- This device will be operable using a standard 9V battery inside the housing
- This device will be operable using a 9V (or higher - TBR) center-negative supply, diode-OR'd with the battery
- The buffer shall be of high enough bandwidth such that the buffered signal sounds identical to the original
- (TBR) This device shall be true bypass
